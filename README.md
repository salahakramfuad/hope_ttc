# 🌟 HopeTTC — Modern Education & Training Platform

**Build Skills. Break Barriers. Go Global.**

HopeTTC is a modern, beautifully designed **Next.js** platform built for an education & training institute offering **IELTS**, **SAT**, **Robotics**, and **Study Abroad** programs.
It features custom theming, smooth hero animations, reusable UI components, and optimized layouts using Tailwind CSS + design tokens.

---

## ✨ Features

- 🎨 **Custom Theme System** with brand color palette (Colors.ts)
- 🌗 **Light & Dark Mode** using CSS variables
- 🚀 **Fast, Responsive UI** with Next.js App Router
- 🧭 **Modern Navigation** with clean UX
- 🤖 **Robotics Program Page** with futuristic design
- 🇬🇧 **IELTS + Spoken English pages**
- 🌍 **Study Overseas Page** with animated gradients
- 📝 **Get Enrolled Form** with honeypot anti-bot field
- 🧩 **Reusable Components:** Nav, HeroIllustration, Metrics, Cards
- 📱 **Fully Mobile Responsive**
- ⚡ **Zero-config Performance Optimized**

---

## 🛠️ Tech Stack

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Lucide Icons**
- **Next/Image** optimization
- **Custom CSS Variables & Theme Tokens**
